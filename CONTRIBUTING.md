# Contributing

For bugs, include the command, checkpoint, benchmark, Python/package versions, and a small reproducible example. Remove access tokens, private paths, and participant information before sharing logs.

For changes to construction, predicates, decoding, or evaluation, explain the intended behavior and run the relevant CPU tests. Keep acceptance separate from fulfillment and preserve benchmark denominators.

Regenerate `MANIFEST.sha256` after staging changes as described in [reproducibility](docs/reproducibility.md). Preserve third-party notices. Contributions must be compatible with Apache License 2.0 for original code.
